2. S037.version_caveat log-versus-applied mismatch (disclosed, benign). The section's
   "new:" line still shows the pre-rephrase value leading with "none"; the applied row
   leads with the v2.1.218 gate. The file's own "Apply-time rephrase" section discloses
   the change, and the other 41 sections match the applied values exactly. A reader of
   only the per-section blocks would quote a value that is not in the shipped file.

3. The score self-test's first aggregation check is vacuous under an empty-return gut.
   "two agreeing grades aggregate cleanly" asserts `r.flat.every(c => c.score === 1)`,
   which is true of an empty array, so it PASSes with aggregateCells gutted; the suite
   only goes red because the NEXT check dereferences a missing cell and throws an
   uncaught TypeError. Exit is non-zero either way, so the gate held here, but the
   redness is accidental rather than designed. Asserting `flat.length > 0` in that check
   would make the tamper detection intentional.

4. tools/tier3-strip.mjs contains two literal NUL bytes (offsets 5844 and 6540), used
   deliberately as join separators in the leak-shingle logic so shingles cannot span
   fields. Side effect: grep classifies the file as binary and suppresses text matches,
   which can silently hide hits in future sweeps over tools/. A visible escape sequence
   (the string backslash-x00 built at runtime) would keep the same semantics and stay
   greppable.

5. The redaction contract lets grader-authored KEY SUGGESTIONS through. The S045 defect
   record reads "Suggest 'per component' as the key value", and the applied S045 and
   S023 keys lead with exactly that framing (the S045 rationale credits the grader
   suggestion openly). Graders wrote those suggestions after seeing the sheets, so
   sheet exposure has a second, permitted route into the v2 keys, narrower than check
   7's finding but the same shape. Worth an explicit rule next round: defect records
   may name what is wrong, not what the new value should be.

6. Defect coverage sits exactly at the floor: 36 distinct scenarios, the minimum the
   spec accepts. Not a defect, but no margin either.
